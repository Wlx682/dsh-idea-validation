# S10 状态持久化与交付物导出

- story_id: S10
- story_points: 3
- sprint_scope: true
- status: completed
- requirement: 想法验证模式不开放通用 shell 或文件修改工具，但 case 必须能跨进程恢复，最终批准的实施交接必须生成可追踪文件。

## 验收标准

1. 有工作区 `cwd` 时，每次成功状态转换把完整 case JSON 原子写入工作区内的受控目录。
2. 内存缓存缺失时，仅凭 `caseId + expectedRevision` 可从同一工作区恢复并继续。
3. `implementation` 最终 `approve` 后，原子导出一份包含目标、Scope、AC、埋点、回滚和关键路径的 Markdown。
4. 所有默认与配置目录必须严格位于 session `cwd` 内，不接受绝对路径或 `..` 越界。
5. 无 `cwd` 的兼容宿主保持原有内存行为；不向 Agent 暴露通用写盘工具。
