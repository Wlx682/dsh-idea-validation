# S5 卡片式人工门禁

- 价值：把隐藏在普通对话文本里的人工门禁恢复成可点击、可补充、可追踪的交互卡片，减少用户不知道该如何回复或误开新 case 的情况。
- Scope：根 Agent 的卡片呈现与答案映射；不改业务阶段顺序，不在子 Agent 中引入人类交互。

## 实现落点设计

- `preset/agent.cordis.yml`：装配 `@deepseek-ai/dsh-tool-ask-user`，并在 persona 中声明卡片优先级和同 case 续跑约束。
- `runtime.js`：为每个非终态 gate 生成机器可读 `CARD_HANDOFF`，包含问题、选项、标签到 decision/humanResponse 的映射，以及 custom 回答策略；system prompt 与命令入口强制根 Agent 先展示卡片、收到答案后再续跑同一 case。
- `test.mjs`：覆盖卡片协议、选项映射、提示词和渲染结果。
- `scripts/idea-validation-dedicated-regression.mjs`：覆盖 preset 确实启用提问工具且不恢复无关文件扫描能力。
